Файлик предназначен для добавления/изменения настроек силоизмерителей.
В качестве силоизмерителя по умолчанию будет установлен тот, который стоит первым.
Результирующее значение (в Ньютонах) вычисляется по формуле S = C*(f-f0), где
f - показания датчика/коробочки
f0 - нулевое значение датчика (определяется автоматически как первое значение в файле)
С = (Номинальная нагрузка *2 *9.81) / 8388608
